## Organizing thesis

Relational complexity is the subject. Information conservation is the
constraint. Admissible transduction is the mechanism.

The new reference formulation is:

> GR says no frame is privileged. QR says: agreed. Select one. Then we can start.

The manuscript identifies this as a methodological formulation, not a quotation
of a GR theorem or a derivation of relativistic frame symmetry. An executing
reference specifies where an account is registered and what context it retains.
Incidence specifies how presentations meet. A compatible comparison law must
then reconcile their orientations. Reference selection cannot manufacture a
missing native interaction, instrument, or chronological source.
