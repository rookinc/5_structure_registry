\begin{proposition}[Finite autonomous recurrence]
A deterministic autonomous machine with a finite complete state space and a fixed finite-valued output map has eventually periodic output. Every limiting symbol frequency therefore exists and is rational.
\end{proposition}
\begin{proof}
Some complete state repeats. Determinism repeats the ensuing future, so the trajectory has a finite transient followed by a periodic orbit of length $q$. If a symbol occurs $k$ times in that orbit, its limiting frequency is $k/q$; the transient contributes zero asymptotic density.
\end{proof}
