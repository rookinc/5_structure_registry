\section{Kernel and WXYZTI Verification Domains}\label{app:kernelreplay}
\subsection{Normalized kernel replay}
The original Audit~028I and Audit~028J Python sources are archived unchanged in \path{provenance/draft3/}. They depend on earlier Project~41 artifacts not all reproduced here. The new \path{scripts/verify_rank8_kernel.py} therefore replays their \emph{explicit normalized formulas}, rather than claiming to rerun the complete historical provenance chain.

The generated report contains the point order, all eight atom matrices, all $64$ multiplication expansions, transpose map, fusion, exact icosahedral comparison and the enumerated color group. It checks the group order and orbitals, the shift-kernel law, the center and derived-group orders, and the five conjugate refinements inside the full fused graph group. Color preservation means preserving each named relation individually; permitting a permutation of relation names is a different automorphism question.

The retained distinction is between a coherent configuration and a group action. The former includes valency-two correspondences. Its matrix products count admissible intermediates. A nonzero matrix commutator is not by itself a realized ordered event, and neither an adjacency matrix nor a Gram matrix is automatically an update rule.

\subsection{WXYZTI row replay and the original contract}
The archived chooser note provides four rows, each containing the six full register states preceding $IW,WX,XY,YZ,ZT,TI$. The new script parses this table, checks all $24$ consecutive transitions, enumerates the $48$ same-channel candidates, and recovers the $12$ opposite-occurrence reciprocal pairs. It also verifies the channel/role permutation algebra. Its input is the realized table, not an independently generated universe of native alternatives.

The archived reconciliation note reports independent recovery of the originally missing reverse rows and makes the domain correction explicit: the historical contract is the ten-transition word $WXYZTITZYXW$, not an arbitrary six-cycle overlay. It reports $61{,}440$ literal fixed-role outward-and-back lifts, all returning trivially. Those historical counts are imported here; the new script does not rerun that entire source packet.

\subsection{What would close the functional crosswalk}
The remaining certificate must supply a common-domain map, not merely a shared product count. At minimum it must specify:
\begin{enumerate}
\item the native source domain, including role occurrence, full register and retained context; a chosen quotient must state which distinctions it forgets;
\item the target type in $\mathscr K_{\rm rel}$ and a source-derived point or relation assignment, independent of the desired answer labels;
\item the image of every transition, reciprocal pairing and channel operation, including all failures and multiplicities;
\item a separately admitted modal reflection and its covariance with $\Cevt$, followed by any required signed-incidence or Gram intertwiner to the twelve-history Born object.
\end{enumerate}
An arbitrary bijection of twelve labels, an equality of binary alphabets, or re-encoding the accepted rows does not satisfy these conditions. A negative result at one map does not refute all context-dependent or path-valued maps. The present package closes the normalized relation algebra and the bounded row replay, while leaving this source-native bridge open.
