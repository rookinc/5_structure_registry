\noindent\textbf{How to read status.} D specifies a definition, P a proved implication, C an executed construction, I an imported result, H a construction hypothesis, and F an unestablished physical correspondence. A mixed label distinguishes these roles; it does not merge them. The full ledger is Appendix~H.

\noindent\textbf{Key distinction.} A convention can select the positive name. It cannot manufacture the incidence, action, or observable that makes that name meaningful in another register. Conversely, a native comparison can be fully covariant without selecting an absolute positive state.
