# Thalean Surface Phase Lift 006
## The surface reference connection admits a D8 phase lift, but not uniquely

### Result

Audit 005 produced a covariant \(O(2)\) reference connection on the local
primitive winding planes.

Its surface loop holonomy is

\[
V_4.
\]

That connection transports the reference without losing local winding, but
its loops do not contain an order-four return.

Audit 006 asks whether the missing quarter-turn appears in a natural
double-cover lift.

It does.

### 1. Two possible central double covers

Write the square rotation/reflection group as

\[
D_8=\langle J,S\mid J^4=S^2=1,\ SJS=J^{-1}\rangle.
\]

The surface edge transports already live in this \(D_8\), while their loop
holonomy lands in the subgroup

\[
\{I,-I,S',-S'\}\cong V_4.
\]

Introduce a central sign \(z\) above the identity.

There are two natural finite lift types.

#### Reflection-square \(+1\)

Use

\[
R^8=1,\qquad
S^2=1,\qquad
SRS=R^{-1}.
\]

The kernel of the projection is

\[
\{1,R^4\}.
\]

#### Reflection-square central sign

Use instead

\[
R^8=1,\qquad
S^2=R^4,\qquad
SRS=R^{-1}.
\]

Again the projection has a central two-element kernel.

These are tested as finite group extensions only. No physical spinor
interpretation is assumed.

### 2. Both extensions can be made flat on every selected face

Choose the canonical lift of each surface edge transport.

A selected dodecagon may return either to \(1\) or to the central sign.

Multiplying an edge lift by the central sign changes the return of every
incident face.

Thus face-flatness becomes a linear system over \(\mathbf F_2\).

For both extension types the system is consistent.

After solving it, all twenty selected dodecagons satisfy

\[
\boxed{
\widetilde P_{\partial f}=1.
}
\]

So the phase lift can coexist with the same genus-21 surface relation.

### 3. The two branches have different loop groups

For the reflection-square \(+1\) branch, the lifted loop holonomy has order
eight and element-order profile

\[
\boxed{
1^1\,2^5\,4^2.
}
\]

Therefore

\[
\boxed{
\widetilde{\mathrm{Hol}}_+=D_8.
}
\]

For the reflection-square-central branch, the profile is

\[
\boxed{
1^1\,2^1\,4^6.
}
\]

Therefore

\[
\boxed{
\widetilde{\mathrm{Hol}}_-=Q_8.
}
\]

The same surface \(V_4\) connection therefore admits two fundamentally
different central lift types.

### 4. The comparator selects the dihedral branch

This is where the independent MM comparator result becomes decisive.

The actual odd-comparator endpoint stabilizer was derived directly as

\[
D_8,
\]

with

\[
1^1\,2^5\,4^2.
\]

Its reflections are genuine involutions.

The quaternionic branch has only one involution total.

Therefore a direct identification with the native comparator symmetry
requires

\[
\boxed{
\widetilde{\mathrm{Hol}}=D_8,
}
\]

not \(Q_8\).

So the local comparator structure removes the extension-type ambiguity:

\[
\boxed{
\text{reflection remains an involution}
\Longrightarrow
\text{dihedral lift}.
}
\]

### 5. The quarter-turn returns in the lift

Inside the selected lifted \(D_8\), there is an order-four element
\(\widetilde q\) satisfying

\[
\boxed{
\widetilde q^{\,2}=z,
}
\]

where \(z\) is the central kernel sign.

Its projection to the surface reference plane is

\[
-I.
\]

Thus the lifted order-four operation is a square root of the surface
half-turn.

Abstractly, this is exactly the same relation already found in the rooted
comparator:

\[
q^2=z.
\]

This is a genuine meeting of the two structures at the group-extension
level.

It is not yet an elementwise identification of the two native operations.

### 6. A major nonuniqueness remains

There are 120 edge-sign choices in the lift.

The twenty face conditions have rank

\[
19.
\]

Therefore the affine space of face-flat lift solutions has dimension

\[
120-19=101.
\]

Changing the sign convention independently at the sixty vertices gives a
59-dimensional gauge space.

After quotienting by that gauge freedom, the number of remaining binary
degrees of freedom is

\[
\boxed{
101-59=42.
}
\]

Hence the selected dihedral extension still has

\[
\boxed{
2^{42}
}
\]

gauge-inequivalent face-flat lifts.

The number \(42\) is not inserted here. It is the first Betti number of the
genus-21 surface:

\[
b_1=2g=42.
\]

So face-flatness determines the local lifting rule but leaves one binary
choice for each independent surface winding direction.

### 7. What this means for the MM target

We have now connected:

\[
\text{surface reference transport}
\]

to

\[
\text{a face-compatible phase lift}
\]

whose selected extension group has the same \(D_8\) relation type as the
native comparator.

The missing quarter-turn can therefore be recovered as a lifted return,
rather than inserted as an unrelated local label.

But the lift is not unique.

The remaining problem has become:

> Which, if any, of the \(2^{42}\) gauge-inequivalent dihedral lifts is
> selected by the native encounter/preparation structure?

That is now the exact place where an additional physical or native rule
would have to enter.

### Boundary

This audit does not identify a preferred lift.

It does not identify the lifted central sign with physical spin,
electromagnetic phase, or \(\hbar\).

It proves a finite central-extension result and uses the independently
derived comparator group only to select the dihedral extension **type**.
